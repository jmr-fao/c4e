# List the data sources read_climate() recognises

List the data sources read_climate() recognises

## Usage

``` r
list_sources()
```

## Value

A character vector of source names, registered ones first.

## See also

[`register_source()`](https://jmr-fao.github.io/c4e/reference/register_source.md)

## Examples

``` r
list_sources()
#> [1] "era5"   "chirps" "wfde5"  "gaez"  
```
